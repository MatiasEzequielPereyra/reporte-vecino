# Roadmap – ReporteVecino

## Fase actual: Arranque del repositorio (Semana 1)

- [x] Estructura del proyecto
- [x] Frontend base (React + Vite + PWA)
- [x] Backend base (Express + memoria)
- [x] Páginas principales (Mapa, Nuevo reporte, Detalle, Admin placeholder)
- [x] Tipos y estilos base
- [ ] Conectar frontend con backend real
- [ ] Agregar base de datos (PostgreSQL o SQLite)
- [ ] Mejorar panel de administración

## Próximos pasos inmediatos

1. Instalar dependencias (`npm install` en frontend y backend)
2. Levantar backend y frontend
3. Probar el flujo completo de creación de reporte
4. Reemplazar datos mock por llamadas reales a la API
5. Agregar base de datos persistente

## Fase 2 – MVP usable (2-4 semanas)

- Persistencia real (PostgreSQL + PostGIS preferible)
- Panel admin con cambio de estados
- Mejor manejo de fotos (compresión)
- Códigos de seguimiento
- Mejoras de UX mobile

## Fase 3 – Piloto real

- Elegir un barrio
- Invitar 15-30 vecinos
- Recolectar feedback
- Corregir problemas de uso

## Fase 4 – Entrega al municipio

- Documentación clara
- Manual de uso para vecinos
- Manual de administración
- Código limpio y comentado
- Posible acompañamiento de las primeras semanas
