# Checklist del MVP

## Debe funcionar

- [ ] Usuario puede abrir la app en el celular (PWA)
- [ ] Puede crear un reporte eligiendo categoría
- [ ] Puede tomar o elegir una foto
- [ ] Puede obtener su ubicación GPS
- [ ] Puede enviar el reporte
- [ ] El reporte aparece en el mapa
- [ ] Se puede ver el detalle y el historial de estados
- [ ] Un administrador puede cambiar el estado del reporte
- [ ] Los cambios de estado se reflejan en el historial

## Nice to have (después del MVP)

- [ ] Compresión de fotos
- [ ] Reportes anónimos vs con cuenta
- [ ] Código de seguimiento para compartir
- [ ] Confirmación de otros vecinos (“sigue igual”)
- [ ] Filtros en el mapa
- [ ] Estadísticas básicas
- [ ] Offline completo (crear reporte sin señal y sincronizar después)
- [ ] Notificaciones push

## Criterio de “listo para piloto”

- El flujo completo funciona sin errores graves
- La interfaz se entiende en menos de 15 segundos
- Funciona bien en Android e iOS (Chrome/Safari)
- Hay al menos un panel admin usable
